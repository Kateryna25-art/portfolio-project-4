###Portfolio Project — Shelly (Jewelry E-Commerce Custom WordPress Theme)
###📌 About the Project
A fully dynamic, custom-developed WordPress & WooCommerce theme built from scratch for the «Shelly» jewelry store.
The project demonstrates the conversion of a custom HTML5/SCSS layout into a fully functional WordPress theme using dynamic PHP templates, custom post types, WooCommerce hooks, Contact Form 7, and Advanced Custom Fields (ACF). Organized with Prettier and Gulp for scalable code structure and high coding standards.
###🛠 Tech Stack
 PHP (Custom WordPress Theme Architecture, Template Hierarchy, Functions & Hooks)
 WooCommerce (Custom e-commerce integration, product templates, cart & checkout flow)
 WordPress Plugins Integration: Advanced Custom Fields (ACF), Contact Form 7
 HTML5 / CSS3 / SCSS (BEM methodology, Responsive Design, CSS Grid & Flexbox)
 JavaScript (Vanilla JS): Interactive UI components & DOM manipulation
 Automation & Code Quality: Gulp, Prettier (PHP plugin)
 Version Control: Git & GitHub
###📁 Theme Architecture & Features
 Custom Theme Files: Dynamic templates (header.php, footer.php, single-product.php, page templates)
 SCSS Source Code: Modular structure with variables, mixins, BEM components, and responsive media queries
 Clean Code Standards: Formatted using Prettier (.prettierrc.json) for consistent code styling across PHP, JS, and SCSS
 E-Commerce Ready: Customized WooCommerce layout, contact forms, and custom fields for dynamic content management
